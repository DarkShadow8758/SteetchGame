# 🎮 Projeto de Jogo

## 📌 Sobre o Projeto

Este projeto foi desenvolvido como parte das atividades acadêmicas, com foco no desenvolvimento de um jogo digital, envolvendo programação, design e criação de assets.

## 👥 Equipe

O projeto foi desenvolvido pelos membros da equipe, responsáveis por diferentes áreas como programação, arte, design e áudio.

## 🎨 Assets e Modelos 3D

Todos os assets utilizados no projeto, incluindo modelos 3D, sprites, texturas e demais recursos visuais, **foram criados pelos próprios membros da equipe**.

Não foram utilizados assets de terceiros neste projeto.

## 🛠️ Tecnologias Utilizadas

* Unity Engine
* C#
* Ferramentas de modelagem e design (como Krita, Blender, entre outras)
